# Ön kayıt — Habersiz oynaklık günü → ertesi gün yukarı; olay günü oynaklığı → aşağı (2026-11-18)

Yazılış: ZA-05 (habersiz düşüş → AL), olay_yukselis EK-1 (H-a/H-b) sonrası. Birleşik hipotez 2018–26 gün içi verisinden çıktı;
**sınav 2008–2017 günlük verisinde** (keşifle örtüşmez) ve 1999–2007'de (takvim yok, bilgi).

## Tanım (günlük ETF; QQQ ana, SPY/DIA/IWM tekrar)
- Oynaklık günü: (H − L) / C ≥ 1,5 × önceki 20 günün ortalaması (yön fark etmez).
- Grup: ABD makro olay günü (CPI/NFP/FOMC/JH) / habersiz.
- İşlem: d kapanışında AL → d+1 kapanışı (2 bp + finansman). Taban: aynı gruptaki tüm günler.
- Korku gecesinden ayrıştırma: V1 günleri (§2.82 UD-01) hariç tutulmuş sürüm ayrıca.

## Ölçüt
- **Habersiz kol:** QQQ 2008–2017'de V1 hariç fark > 0 ∧ P ≥ 0,95 ∧ SPY/DIA/IWM'nin ≥ 2'sinde fark > 0 → B ("habersiz oynaklık ertesi
  gün AL"). P altı → C+. Değilse X.
- **Olay kolu:** QQQ'da V1 hariç fark < 0 ∧ ≥ 2/3 ETF'te aynı → C+ (veto/SAT etiketi; olay günü az, P beklenmez). Değilse X.
- Bilgi: 1999–2007 (takvimsiz, tüm oynaklık günleri), yön (yukarı/aşağı gün) ayrımı.
